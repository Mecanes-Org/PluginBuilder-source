# PluginBuild
PluginBuild est un outil léger et efficace conçu pour automatiser le build, l’organisation et l’exportation de vos plugins Unreal Engine. En un clic, compilez vos plugins pour plusieurs versions d’Unreal, générez des dossiers prêts pour Fab, et accélérez votre workflow de développement. Simple, rapide, indispensable.
